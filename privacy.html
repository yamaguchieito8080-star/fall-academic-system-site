Privacy policy

Fall Academic System. Last updated 16 October 2026.

Fall Academic System is a personal study planner used only by its owner, Eito Yamaguchi. This policy explains what happens to Google account data when the owner connects the app to Google.

What the app accesses

  • Google Tasks: the app creates, updates and reads tasks in one task list that it creates itself, named "Fall Academic System". It reads the completion status of those tasks.
  • Google Calendar: the app creates, updates and deletes events in one secondary calendar that it creates itself, named "Fall Academic System". It does not read or change any other calendar.

How the data is used

The data is used for one purpose only: to show the owner's assignment deadlines in Google Calendar and Google Tasks, and to mark an assignment done in the app when its task is completed in Google Tasks.

Where the data is stored

The sign-in token that Google issues is stored in a file on the owner's own computer. Assignment data is stored in files on the same computer. Nothing is stored on any other server, and the app has no database, analytics, advertising or tracking.

Sharing

Google user data is not sold, shared, transferred or disclosed to anyone. It is not used for advertising, and it is not used to train any artificial intelligence or machine learning model.

Retention and deletion

The owner can disconnect Google from inside the app at any time, which deletes the stored token. Access can also be revoked at myaccount.google.com/permissions. The calendar and task list the app created can be deleted from Google Calendar and Google Tasks.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
